# GPT 컨셉 시트·재질 견본

GPT 이미지는 **방향을 정하는 그림**과 **재질 견본**까지만 쓴다. 그대로 텍스처가 되지 않는다:
확산 모델은 픽셀 격자·고정 팔레트가 없고(격자 어긋남, 번진 가장자리, 넘치는 색), 출력은 1024px 급이며,
커스텀 몹의 면별 UV 배치를 모른다(배치가 고정된 64×64 스킨도 직접 생성하면 부위가 자주 틀린다는 2026 연구).
그림 맡기기 자체의 절차(프롬프트 파일, 받는 폴더, 채팅 본문에도 붙이기)는 `gpt-collab` 스킬을 따른다.

## 1. 컨셉 시트 프롬프트 (보스·정예 새 디자인, 큰 보강 전에)
```
마인크래프트 RPG 서버의 커스텀 몹 컨셉 시트. 몹: <이름> — <던전 테마>, <역할: 일반/정예/보스>, <공격 방식 한 줄>.
- 정면, 옆면, 뒷면 3개를 같은 크기·같은 높이로 나란히 (정사영, 원근 없음), 단색 회색 배경, 그림자 없음
- 블록형 3D 모델로 만들 수 있는 형태: 직육면체 덩어리, 둥근 곳도 계단 없이 큰 상자 몇 개로
- 키는 플레이어의 <n>배, 실루엣이 멀리서 읽히게: <두건/뿔/어깨/무기> 강조
- 색: <던전 팔레트 3~5색 hex>, 포인트 색 1개 <hex>
- 질감 표현은 평평한 색 + 1px 어두운 테두리 느낌, 사진 질감·부드러운 그라데이션 금지
- 같은 던전 기존 몹과 어울리게: <기준 모델 설명 한 줄>
```
받은 시트는 설계 파일 주석에 "참고: input/gpt/<주제>-vN/<파일>"로 적고, 부품 목록(2장의 순서)으로 옮긴다.

## 2. 재질 견본 프롬프트 (텍스처를 다시 그릴 때)
```
마인크래프트 16x 스타일 재질 견본 한 장: <뼈 / 녹슨 철 / 낡은 천 / 젖은 모래 / 이끼 낀 돌>.
- 16×16 픽셀 타일 4개를 2×2로 (각 타일은 정확히 16×16 픽셀 격자, 확대해서 보여 줘도 됨: 1픽셀 = 16×16 칸)
- 팔레트 <n>색 이하: <hex 목록> (그림자는 살짝 파랑·보라 쪽, 밝은 곳은 살짝 노랑 쪽)
- 무늬는 재질 정보만(결, 금, 녹), 무작위 점 잡음 금지, 안티앨리어싱 금지, 순흑 금지
```

## 3. 받은 그림 처리 (코드)
1. 격자 복원: 확대된 픽셀 크기를 추정해 블록마다 대표색으로 줄인다(가장자리 간격의 최빈값 → 격자 오프셋 → 블록 투표).
   외부 도구(unfake.js, Pixel Snapper)는 사용자 승인 뒤에만 설치·실행. 간단한 경우는 Pillow 로 직접.
2. 팔레트 스냅: Pillow `quantize(palette=…, dither=NONE)` — 디더 없이 가장 가까운 색. 결과에 팔레트 밖 색 0.
3. 면 배치: 견본을 각 면 크기로 잘라 넣고(1 px/유닛), `reshade.py --mode adjust` 로 테두리·위 밝음 구조를 얹는다.
4. 얼굴·문양·포인트는 사람이 픽셀 단위로 마감(면 목록을 넘긴다).
