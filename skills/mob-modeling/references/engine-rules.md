# ModelEngine R4 규칙과 검사 항목 (lint.py)

근거: ModelEngine 공식 위키(2026-08~11 갱신본), MythicMobs·ItemsAdder 문서, BetterModel 저장소. 버전은 R4.1.1 기준.
문서에 없는 것(본당 크기 한계, 1.21.11 이후 자유 회전 지원 여부)은 **인게임 확인 전까지 경고**로 둔다.

## 1. 모델 파일
- 형식: Blockbench **Generic Model**(`model_format: free`). 파일 이름이 곧 모델 ID → 팩끼리 이름이 겹치면 덮어쓴다. 새 팩은 접두사로 구분.
- 메시(mesh) 요소 금지. Bezier 보간은 linear 로 재생된다(손맛이 Blockbench 미리보기와 다름). 내부 처리 초당 20틱.
- 큐브 회전: **한 축만, 0·±22.5·±45°**. 뼈(그룹) 회전은 제한 없음. (마인크래프트 1.21.11 부터 블록 모델은 다축 회전을 허용하지만 ME 문서는 반영 안 함)
- 텍스처는 파일 안에 넣는다. **2의 거듭제곱**이 아니면 아틀라스 전체의 mipmap 이 낮아진다(멀리서 뭉개짐).
- 텍스처마다 UV 크기(`uv_width`/`uv_height`)를 다르게 두는 것은 Blockbench 4.9+ 기능인데 ME 처리 방식이 문서에 없다 →
  스킬 도구는 원래 UV 크기를 지킨다(밀도 맞추기는 면 좌표만 비례로 바꿈, 부품 새 텍스처는 프로젝트 해상도). 예외: `--pow2` 는
  캔버스를 늘린 만큼 그 텍스처의 UV 크기를 늘린다 → 인게임 확인 항목.
- 발광: 1.21.2 이상 클라이언트에서만. 불투명도 1% 이상인 발광 픽셀은 완전 불투명으로 그려진다 → 부드러운 글로우 금지.

## 2. 특수 뼈 (이름 접두사)
| 접두사 | 뜻 | 규칙 |
|---|---|---|
| `hitbox` | 몹 판정 상자 | 큐브 1개, 가로=깊이(넓은 쪽만 읽음), 64블록 이하, 기준점 Y 가 눈높이, **Y<0 이면 질식 피해**, 애니메이션 불가 |
| `shadow` | 그림자 크기 | |
| `h_` / `hi_` | 머리(시선 따라 돎) / 상속 | `h_` 자식에 `h_` 가 없으면 머리를 따라가지 않음 |
| `ir_` `il_` `ih_` | 손·머리 아이템 표시 | **큐브 없어야 함** |
| `l_` | 리드 연결 지점 | **큐브 없어야 함** — 팩이 팔·다리를 `l_a`·`l_l` 로 지은 경우 충돌 경고 |
| `seg_` `tl_` | 체인 마디·꼬리 | R4.0.7 부터 **큐브 없어야 함** |
| `mount` `p_` | 탑승 | |
| `b_` `ob_` | 보조 판정 상자 | 렌더 안 됨 |
| `tag_` | 이름표 | |
태그 충돌은 이름을 바꾸면 풀리지만, 기존 뼈 이름은 서버 설정·스킬이 부를 수 있어 **사용자 결정**이다(인게임에서 실제로 문제인지 먼저 확인).

## 3. 성능 (예산은 공식 수치 없음 → 시작값)
- 비용 단위는 **렌더 뼈(큐브가 든 뼈) 1개 = 디스플레이 엔티티 1개**. 큐브 수보다 뼈 수가 중요하다.
  → 디테일은 **기존 뼈 안에 큐브로** 더하면 엔티티 수가 늘지 않는다(`kitbash.py` 규칙).
- 대역폭 ≈ 움직이는 렌더 뼈 × 초당 20회 × 시청자 수. 경쟁 플러그인 측 측정(구버전 ME)으로 모델 1마리·시청자 1명당 약 28 kbit/s.
- 설정: ME 컬링(수직 거리, 시야 뒤, 가려짐, 거리별 갱신 감소)은 모두 켠다.
| 등급 | 동시 등장 | 렌더 뼈 | 본체 텍스처 |
|---|---|---|---|
| 일반 | 방당 10~20 | 6~12 | 64~128 |
| 정예·중간보스 | 2~5 | 12~25 | 128~256 |
| 보스 | 1 | 25~50 | 256 (1~2장) |
- 뼈가 수백 개인 보스(예: 마디 359개 지네)는 렌더 뼈 수부터 잰다.

## 4. lint.py 판정 읽기
| 표시 | 뜻 | 할 일 |
|---|---|---|
| 오류: 메시 / 텍스처 없음 / hitbox Y<0 | 서버에서 깨지거나 피해 | 고치기 전 적용 금지 |
| 경고: 형식 free 아님 | ME 문서 밖 (bedrock 형식이 서버에서 쓰이는 사례는 있음) | 인게임 확인 |
| 경고: 큐브 회전 규칙 밖 | 다축·비표준 각 | 인게임 확인 → 규칙 판정 |
| 경고: 2의 거듭제곱 아님 | mipmap 저하 | `density_fix.py --pow2` — 캔버스만 늘리고 UV 단위를 같이 늘림(밀도·모습 유지, 발광 짝도) |
| 경고: 태그 뼈에 큐브 | 큐브가 안 보이거나 태그 동작 | 인게임 확인 → 이름 변경은 사용자 결정 |
| 경고: Bezier | linear 로 재생 | 동작 손맛 확인, 필요하면 catmullrom 으로 다시 (blender-motion) |
| 경고: 소수 크기 큐브 많음 | 통째 확대·축소 흔적 → 밀도 불일치 | `density_fix.py` |
| 경고: 같은 평면에 겹친 면 | 기본 자세에서 같은 평면·같은 방향 면이 겹침 → 인게임 깜박임 | 부품 좌표를 1칸 옮기거나 덮인 면 `skip` (원본끼리 겹침은 팩 원래 문제) |
| 경고: 뒤집힌 큐브(from>to) | Blockbench 양면 표현용 복사본 → 큐브 수에서 뺌. ME·인게임 표시 미확인 | 인게임 확인. 새 부품은 `skip` 으로 맞닿는 면을 처리 |
| 경고: 본체 텍스처 3장 이상 | 리소스팩·아틀라스 부담, 기준은 본체 1 + 발광 1 | 부품은 원본 빈 곳에 (kitbash 기본) |
| `[공통]` 텍셀 밀도·믹셀·색 위생·명도 하한·렌더 뼈 | 1층 공통 규칙 밖 (common-rules.md) | 처방표(SKILL.md 3단계), 일부러면 예외 승인 |
| `[스타일 …]` 범위 밖 | 그 몹 프로필 범위 밖 (style-profiles.md) | 처방표, 프로필·역할 지정이 맞는지 먼저 확인 |

## 5. 서버 적용 (사용자 지시 때만)
1. `plugins/ModelEngine/blueprints/` 의 원본 .bbmodel 을 백업한다.
2. 복사본(`작업/모델링/모델/…`)으로 교체 → `/meg reload` → 콘솔 경고와 `limits mip level` 로그를 읽는다.
3. ItemsAdder 를 쓰면 `merge_other_plugins_resourcepacks_folders` 에 `ModelEngine/resource pack` 이 있는지 보고 `/iazip`.
4. 인게임 라인업: 같은 던전 몹을 나란히, 밝기 0·7·15, 거리 4·16·32블록에서 스크린샷. 흑백 실루엣만으로 종류가 구분되는지.
5. BetterModel 로 옮길 가능성을 남기려면: Generic, 메시 없음, Bezier 없음, 22.5° 큐브, 공통 태그만.
