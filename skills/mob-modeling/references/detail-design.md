# 부품 보강 설계 (make_detail.py · kitbash.py)

목표는 큐브 수가 아니라 **같은 프로필 기준 몹 옆에 섰을 때 같은 게임처럼 보이는 실루엣과 재질 구분**이다.
Blockbench 가이드: 알아볼 수 있는 한 요소는 적게, 둥근 물체는 요소 하나로. 디테일이 촘촘한 모델(예: 해골 계열)은 큐브의 절반쯤이 얇은 판이다.

## 1. 설계 전에 볼 것 (순서대로)
1. **뼈 트리**: `blender-motion/scripts/inspect_model.py <모델>` — 뼈가 부모·자식으로 이어졌는지, 형제인지.
   형제 구조(머리·몸·팔·다리가 모두 루트 아래)면 **몸에 붙인 긴 천을 다리가 뚫는다** → 다리 부품은 다리 뼈에.
2. **동작 범위**: 각 뼈가 공격·등장·사망에서 몇 도 도는지(`inspect_model.py --keys <동작>`, 또는 bbpose 로 샘플링).
   기준점에서 멀리 뻗은 부품일수록 많이 휩쓴다(거리 × sin각). 다리 −61° 면 기준점 아래 10칸 부품이 앞으로 8~9칸 움직인다.
   크기(scale) 키가 있는 뼈(예: 공격 때 팔이 세로 2배)는 붙인 부품도 같이 늘어난다 → 동작 자세 시트로 확인.
3. **겹칠 자리**: 기존 큐브 면과 같은 평면(같은 좌표)·같은 방향에 새 면을 두면 깜박인다(z-fighting). `print(kit.cubes("뼈"))` 로
   기존 큐브 좌표를 보고 설계하고, `make_detail.py --no-render` 의 "같은 평면에 겹친 면" 경고가 **0** 이 될 때까지 고친다.
   얇은 판(두께 0.025 같은 것), 뒤집힌 큐브(from>to, 안쪽 면 표시용 복사본)가 있는 자리를 특히 본다.
   다른 뼈의 큐브와도 기본 자세에서 같은 평면이면 깜박인다(뼈가 달라도 서 있을 때는 같은 자리).
4. **원래 주요 색**: 설계 파일 `build(kit)` 안에서 `print(kit.colors())` — 본체 면이 실제로 쓰는 픽셀의 (hex, 비율, OKLab L, 명도 V).
   **몸 재질**(살·뼈·껍질)은 여기서 고른다. **장비 재질**(천·금속·가죽)은 같은 프로필 기준 몹의 재질 계열이나 던전 테마 색에서 고른다 —
   원본이 한 색뿐인 몹에 원본 색만 쓰면 재질 대비가 사라진다. 포인트 색은 1개 (6장).
5. **장비**: MythicMobs 설정에 Equipment(손에 든 아이템)가 있으면 무기 큐브를 만들지 않는다(이중으로 보임). 무기를 직접 만들 때는
   큐브를 **팔 뼈**에 붙인다 — 큐브가 없던 뼈(예: 태그 뼈 `ir_`·`il_` 의 부모 마커)에 붙이면 렌더 뼈가 1개 는다(kit 이 알림).
6. **이 몹의 정체**: 이름·던전 테마·공격 패턴(무기 뼈, 손에 든 것, 마법 위치). 패턴이 정해져 있으면 필요한 부위가 정해진다.

## 2. 무엇을 더하나 (멀리서 읽히는 순서)
1. **머리 실루엣**: 두건·투구·뿔·왕관·후드 끝. 머리는 가장 많이 보는 곳.
2. **어깨·팔**: 어깨 판, 넓은 소매(위는 좁고 아래는 넓게 두 단), 팔찌·족쇄.
3. **허리·다리**: 치마·찢어진 천(반쪽씩 다리 뼈에), 허리띠·감개, 늘어진 천 판.
4. **손에 든 것**: 무기·등불·책·지팡이. 공격 동작에서 함께 휘두르므로 손잡이를 쥔 모양이 자연스럽다(매단 물건은 막대처럼 뻗는다).
5. **작은 포인트**: 빛나는 눈·보석·불 1곳. 색 포인트가 많으면 산만하다.
기준: 그 몹 프로필의 큐브/키 하한(`lint.py` 의 `[스타일]`). 슬라임·불꽃처럼 단순함이 의도면 역할을 `소환` 으로 두거나 라인업으로 판정.

## 3. kitbash API
```python
kit.material("robe", "#9aa6a9", half=0.25, center=0.68)    # 기준색, 계단 폭(OKLab 밝기 ±), 중심 밝기
kit.cube(뼈, [x,y,z], [x,y,z], 재질, 종류, 이름, skip=[면], rot=("x", -22.5), opts=dict(...))
kit.mirror_x(...)                                           # x 를 뒤집은 짝 (east/west skip 도 바뀜)
kit.colors(8)                                               # 원본 주요 색 [(hex, 비율, 밝기)]
```
- 좌표는 정수만(아니면 멈춤: 믹셀 방지). 회전은 한 축 0·±22.5·±45 만(아니면 멈춤). 두께 0 판은 앞뒤 면만 생긴다.
- `skip`: 안 보이는 면(안쪽, 맞닿는 면, 열린 아래)에는 텍스처를 주지 않는다 → 깜박임·낭비 방지.
- 부품 텍스처는 새 텍스처(원본 UV 해상도와 같은 크기)에 자동 배치. 모자라면 한 장 더(`_detail2`).
| 종류 | 칠하는 법 | opts |
|---|---|---|
| `cloth` | 불규칙 세로 주름(어두운 줄+밝은 줄), 찢어진 밑단(투명). `bands=N` 은 N px 마다 가로 줄(붕대·감은 천) | `hem`, `hem_depth`, `folds`, `bands` |
| `metal` | 두께 2px 이상 면은 윗줄 반짝임·아랫줄 그늘, 3×3 이상 면 테두리, 5×5 이상 면 모서리 징 | `rivets` |
| `plain` | 맨살·뼈·나무: 가운데 살짝 밝게 + 얼룩 | |
| `hair` | 세로 가닥, 들쭉날쭉 끝 | `hem_depth` |
| `glow` | 테두리 없이 가운데로 갈수록 밝게 | |
| `dark` | 구멍·그림자 속 (계단 1.5칸 어둡게) | |
공통 opts: `grad`(옆면 위→아래 밝기 차, 0.16), `center`, `noise`, `edge`(테두리 칸 수, 1.0), `shift`(계단 이동).
크기 조건: 테두리는 4×4 이상 면(금속 3×3), 가운데 밝게는 5×5 이상. 재질 인자: `steps`(계단 수, 기본 6), `half`(계단 폭), `center`(중심 L).

**칠하기 기본값**: 프로필의 `paint` 묶음(make_profile 이 기준 몹에서 정함) → `kit.defaults(…)` → `material(opts=…)` → `cube(opts=…)` 순으로 덮어쓴다.
평면 스타일(테두리 없음)은 `edge=0, center=0, noise=0`, 팔레트가 좁은 팩은 `hue_shift=0`(색상 이동 없이 밝기만) 또는
`material(…, palette=["#19212d", …])`(계단 색을 팩 팔레트에서 고름). 계단 수가 적으면(3~4) 윗면 +반 칸이 반올림으로 한 칸이 되어
색이 하나 는다 → `shift=-0.1` 로 내리거나 계단을 5~6 으로.

**재질 center 는 OKLab 밝기 L** 이고, 아트 기준의 명도는 HSV V 다. 회색 기준 환산:
| 명도 V | 0.20 | 0.30 | 0.40 | 0.50 | 0.60 | 0.65 | 0.80 |
|---|---|---|---|---|---|---|---|
| OKLab L | 0.32 | 0.42 | 0.51 | 0.60 | 0.68 | 0.73 | 0.85 |
**색 예산**: 결과 색95 ≈ 원본 색95 + 부품이 쓴 색. 재질 5개 × 6계단이면 30색까지 늘 수 있다 → 프로필 색95 상한에 걸리면
재질별 `steps=4~5`, 재질 수 줄이기, `palette=[…]` 로 원본 색 재사용. 보고표에 "색 예산" 줄과 재질별 픽셀·쓴 색이 나온다.
**재질 대비는 밝기가 아니라 색상·채도로**: 금속을 한 계단 밝게(`shift`) 하면 뼈의 밝은 색과 같아져 금속감이 사라졌다(모래 해골 v3).

보고표의 "재질" 표에 재질별 계단의 L·V 범위가 나온다. 명도 기준은 하나다: **모델 평균 명도가 `lint` 의 "실효 목표"
(1층 하한 ∩ 프로필 범위) 안**. 몸 대부분이 아주 어두우면 평균이 맞아도 어두운 곳 줄(조명 50%)에서 형태가 보이는지 본다.
부품 면은 원본 텍스처의 연속된 빈 영역에 1px 간격으로 모이고, 그런 영역이 없을 때만 새 텍스처가 생긴다.

**좌표 격자**: 크기는 정수. 위치는 정수이거나 그 뼈의 기존 큐브가 쓰는 소수 부분(예: 머리가 x ±4.5 면 .5)이어야 한다 —
몸 픽셀과 부품 픽셀이 같은 격자에 놓인다. 기준점(origin, 회전 중심)은 소수여도 된다.

**회전 부호**(Blockbench 큐브 회전, `rot=(축, 각)`): x **−** 면 뒤(+z) 끝이 올라가고 앞(−z) 끝이 내려간다, x + 는 반대.
z **+** 면 +x 끝이 올라간다. y + 면 위에서 볼 때 +x 끝이 앞(−z)으로 돈다. `mirror_x` 는 y·z 부호를 뒤집는다.

**꺾인 두 마디 부품**(뿔·발톱·꼬리 끝): 회전이 다른 두 조각이 옆면 평면을 공유하면 이음매에 쐐기 겹침이 생긴다(`[새 겹침]`).
한 조각을 그 평면에서 1칸 옮기거나 폭을 1칸 다르게 한다. 회전한 조각의 끝점은 정수가 아니므로, 다음 조각은 끝점 근처의
정수 위치에 두고 기준점(origin)을 끝점에 맞춘다. 마디가 많으면 마디마다 뼈를 두는 대신 같은 뼈에 짧은 조각 2~3개로 끝낸다.

## 4. 시험에서 배운 것 (사당의 망령 1·2차, 2026-11-14)
- 두건 윗면을 머리보다 큰 판으로 두면 **모자 뚜껑**처럼 보인다 → 머리를 감싸는 껍데기(얼굴 쪽 `north`·아래 `skip`) + 차양 + 뒤로 처진 끝.
- 소매를 통짜 상자로 두면 둔하다 → 위는 팔보다 1칸 크게, 아래는 넓게(두 단) + 끝 띠.
- 같은 간격 주름은 줄무늬처럼 보인다 → 불규칙 간격, 어두운 줄 옆에 밝은 줄.
- 몸통 망토를 길게 두면 다리가 뒤로 휘두를 때 뚫는다 → 허리까지.
- 매단 등불은 공격 때 팔과 함께 막대처럼 앞으로 뻗는다(엔진에 물리 없음) → 손잡이를 쥔 모양이 낫다.
- (엔더 찢개, end 프로필) 가는 몸에 뿔·어깨·등 가시를 많이 달면 정체성이 바뀐다("마른 엔더맨 → 갑옷 악마") → 큐브/키 하한을
  맞추는 것보다 실루엣 정체성이 먼저. 하한을 넘기려고 부품을 늘리기 전에 사람 판정. 평면 스타일 부품은 무늬 없는 평면이라
  원래 몸의 무늬 옆에서 매끈해 보일 수 있다 → 원래 무늬 색 2~3개를 `palette` 로 섞는다.
- 텍스처만 다시 칠해서는 형태가 단순한 모델이 기준 모델처럼 보이지 않는다. 다시 칠하기는 원래 색 유지(`adjust`)가 기본.
- 결과 수준: 실루엣·디테일 수치는 기준 근처까지 오지만(큐브/키 4.5 → 18.6), 재질 대비(뼈·쇠·가죽 섞임)와 디자인 완성도는
  기준 몹보다 한 단계 아래 → **보스·정예는 사람 판정과 GUI 다듬기를 전제**로 한다.

- 같은 평면 겹침은 눈으로 거의 안 보인다(렌더 크기에서). 템플릿 1차 설계에도 34쌍이 있었다 → 검사 숫자로 잡는다. 고치는 법:
  - 감싸는 부품은 감싸는 쪽 **모든 면을 1칸 크게** (치마는 다리보다 앞뒤 1칸, 윗면은 다리 윗면보다 1칸 위)
  - 다른 부품이 덮는 면은 `skip` (소매 끝 띠가 덮는 소매 윗면, 두 반쪽이 맞닿는 안쪽 면)
  - 매다는 물건은 다른 부품 부피 밖에 (등불은 치마 바깥 x>4)
  - 가슴 앞을 덮는 판(머리카락 등)이 있으면, 그 판 평면(z)을 피해 소매·치마 앞면을 1칸 앞에
- 머리보다 1칸 큰 두건 껍데기에 앞면을 열면, 머리와 벽 사이 틈이 얼굴 둘레 고리처럼 비쳐 보인다 → 어두운 안쪽 테(`dark`)로 막되,
  바깥 벽과 같은 평면인 옆면은 `skip`.
- 팔이 몸통 바로 옆에 붙은 몹(팔 x 4~6)은 "감싸는 부품 1칸 크게"가 손·허리띠 충돌을 만든다 → 허리띠는 손 높이 아래·위로 피하고,
  팔 붕대의 몸 쪽 안쪽 면은 `skip`(틈은 몸이 가린다).
- 기울인 판·45° 끈도 겹침 검사는 실제 다각형 넓이로 잰다(축 정렬 상자로 어림하지 않음) — 기울인 어깨판 안쪽 모서리가 얼굴 앞면과
  겹치면 진짜 겹침이다.
- 수치(색95·채도·명도)는 텍스처 **픽셀** 기준이다: 거의 안 보이는 면(아랫면·안쪽)도 똑같이 센다. 면을 `skip` 하면 수치가 바뀐다.
- 큐브 수: `lint`·보고표는 **렌더되는 본체 큐브**(히트박스·뒤집힌 양면 복사본 제외), `inspect_model.py` 는 파일의 모든 큐브를 센다.

## 6. 색 방침
- 재질 기준색은 원본 색에서 고른다. 포인트 색(빛·보석·눈)은 몹마다 1개.
- 원본이 회색·검정 한 가지뿐인 몹(망령 등)은 포인트 1개로는 팔레트 거리가 줄지 않는다 → **던전 테마색**(그 던전 이펙트·조명의 색,
  예: 황혼 묘역의 청록 혼불)을 포인트로 쓸 수 있다. 처음 쓰는 테마색은 라인업으로 사용자 승인을 받고 기준 파일 프로필 `_설명` 에 적는다.
