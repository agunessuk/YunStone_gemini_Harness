# 2층 스타일 프로필 (프로젝트마다, 여러 개)

1층(공통 규칙)을 지킨 위에서 "어떤 느낌으로 칠하고 얼마나 촘촘하게 만드나"를 정한다.
프로필 = 기준 몹 몇 개를 잰 범위: 명도·채도·명암 폭·노이즈·테두리 어두움·위 밝음·색 수(95%)·큐브/키(높이 1블록당 큐브).
`lint.py` 가 `[스타일 <프로필>·<역할>·<테마>]` 표시로 검사한다.

## 1. 기준 몹 고르기
- 그 스타일로 **"이렇게 보이면 좋겠다"** 는 몹 3개 이상 (1~2개면 범위가 너무 좁다). 플레이어가 자주 보는 몹이면 더 좋다.
- 기준 몹이 1층 공통 규칙을 크게 어기지 않아야 한다 (`lint.py`). 밀도가 튀는 몹은 기준으로 삼지 않는다.
  명도처럼 조금 어기면(예: 엔드 몹이 너무 어두움) 프로필은 그대로 만들고, 1층이 우선 적용된다(실효 범위 = 두 층의 겹치는 구간).
- 몹을 고르는 것은 사용자 결정이다. 고르기 전에 `lineup.py` 로 후보를 나란히 세워 보여 준다.

## 2. 만들기·지정
```
python -I <스킬>/scripts/make_profile.py --name fantasy --note "해골 계열 거친 판타지" --default skeleton_warrior skeleton_archer skeleton_shaman
python -I <스킬>/scripts/make_profile.py --name end --note "엔드·평면" end_seeker void_beholder ender_witch
python -I <스킬>/scripts/make_profile.py --name end --assign ender_ripper,ender_clam --role 일반
python -I <스킬>/scripts/make_profile.py --name end --assign hv_tenebris --role 보스
python -I <스킬>/scripts/make_profile.py --show
```
- 기준 파일이 없으면 템플릿에서 새로 만든다(`작업/모델링/기준.json` 또는 `modeling/art_standard.json`). 바로 전 판은 `.bak`.
- 범위 공식: 기준 최소 − 여유 ~ 최대 + 여유 (명도 ±0.08, 명암 폭 ±0.04, 노이즈 ±0.02, 테두리 ±0.15, 채도 ±0.10, 위밝음 ±0.08),
  색95 = 최소×0.7 ~ 최대×1.4, 큐브/키 하한 = 최소×0.6 (정예 ×0.8, 보스 ×0.5, 소환은 없음 — 큰 몹은 키가 커서 높이당 큐브가 적게 나온다).
- 다시 만들면 범위가 새로 계산된다. 손으로 넣은 `themes` 는 유지된다. 범위를 손으로 고쳐도 되지만 이유를 `_설명` 에 적는다.
- **손으로 정한 하한**(예: 기준 몹이 단순해 "디테일 살리기" 목표로 큐브/키 하한을 올림)은 기준 몹 자신도 경고가 뜬다 — 의도한 것인지
  사용자 승인을 받고 `_설명` 에 적는다. 라인업 COMPARE 에는 그 하한을 넘는 몹(이미 보강한 몹)을 함께 세운다. 하한을 맞추려고
  부품을 늘리다 정체성이 바뀌면(detail-design 4장) 하한을 낮추는 것이 맞다.
- **칠하기 묶음** `paint`: make_profile 이 기준 몹에서 정한다(테두리 있으면 edge 1·center 0.08, 결이 있으면 noise 0.06,
  색이 적으면 hue_shift 0). make_detail 의 부품 칠하기와 RESHADE 기본값이 된다. 손으로 고쳐도 된다.
- 지정 순서: 명령의 `--profile`·`--role`·`--theme` > 기준 파일 `assign` > `default_profile`.

## 3. 역할과 테마
- 역할(`일반`·`정예`·`보스`·`소환`): 큐브/키 하한과 렌더 뼈 예산(1층)이 달라진다.
- 테마: 같은 프로필 안의 변형. 예) 어두운 테마 `"themes": {"dark": {"val": [0.30, 0.55]}}` — 1층 명도 하한(0.25)은 그대로 적용된다.

## 4. 안전장치 (기준이 많으면 기준이 없는 것과 같다)
- 프로젝트 전체 프로필 **2~3개**까지. 늘리기 전에 기존 프로필에 테마를 두는 것으로 안 되는지 본다.
- **한 화면에 같이 나오는 몹은 한 프로필**: 던전(지역) 하나 = 프로필 하나. 여러 던전에 나오는 몹은 그 몹이 가장 많이 나오는 쪽.
- 프로필끼리 차이는 명도·채도·테두리 같은 칠하는 방식에서 나게 하고, 픽셀 크기(1층)는 절대 다르게 하지 않는다.
- 수치는 비례·형태 언어·색 온도를 못 잡는다 → 프로필마다 라인업(같은 프로필 몹을 나란히)을 사람이 승인한다.

## 5. 예시 (베어타이쿤 던전팩, 2026-11)
| 프로필 | 기준 몹 | 쓰는 곳 | 성격 |
|---|---|---|---|
| `fantasy` (기본) | skeleton_warrior·archer·shaman | 기존 던전 5곳, 모래 왕묘, 황혼 묘역, 금지된 서고 | 면마다 1px 어두운 테두리, 명암 폭 큼, 큐브 촘촘(높이당 30~42) |
| `end` | samus2002 엔드 몹 | 심연 균열 | 어둡고 평평한 색면, 테두리 거의 없음 |
단색 몹(망령 등)의 포인트 색은 그 던전 이펙트 색(예: 황혼 묘역 청록)을 쓸 수 있다 — 처음 쓸 때 라인업으로 승인받고 `_설명` 에 적는다.
