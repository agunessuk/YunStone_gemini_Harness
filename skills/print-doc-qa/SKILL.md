# 인쇄 문서 검수

FOD-skills `visual-output-qa`의 "직접 본다" 원칙을 문서에 맞게 줄였다. 근거: 시험지·설명회 자료에서 같은 레이아웃 지적이 반복됨.

## 언제
- 시험지, 학습지, 교재 페이지, 홍보물, 표지, PPT를 PDF·이미지로 내보내기 전
- 레이아웃 피드백을 반영한 뒤

## 순서
1. 최종 형식으로 렌더링한다(PDF면 PDF). 페이지마다 PNG로 뽑아 직접 본다. 전체를 축소 시트로 훑고, 의심 부분은 원본 크기로 연다.
2. 아래 표를 페이지마다 확인한다.
3. 고친 뒤 다시 렌더링해서 본다. 고친 페이지만이 아니라 밀려난 뒤 페이지도 본다.
4. 보낼 때 확인한 항목과 남은 문제를 짧게 쓴다.

## 볼 것
| 항목 | 기준 |
|---|---|
| 줄바꿈 | 문장이 어색하게 끊기지 않는다. 오른쪽 끝까지 채운다. 수식·단어 중간에서 끊기지 않는다 |
| 간격 | 문항 사이 간격이 일정하다. 풀이 공간은 문항 종류에 맞다 |
| 하단 공백 | 페이지 아래에 큰 빈 공간이 없다. 있으면 문항 배치를 바꾼다 |
| 정렬 | 제목은 가로·세로 모두 가운데. 본문과 부가 정보의 정렬 방식이 구분된다 |
| 크기 | 역할이 같은 글자는 같은 크기. 글자를 키웠으면 배경 박스와 주변 영역도 함께 맞춘다 |
| 넘침 | 글자가 박스·페이지 밖으로 넘치지 않는다 |
| 누락 | 요청 범위(유형 1번~끝, 모든 단원, 모든 학년)가 빠짐없이 들어갔다. 스크립트로 개수를 센다 |
| 군더더기 | AI가 덧붙인 안내 문구, 관찰용 라벨, 요청 없는 소개란이 없다 |
| 말투 | 학생용 문서는 시험체("고르시오", "쓰시오"). 채팅 말투가 섞이지 않는다 |
| 고유명사 | 학원명, 강사명, 날짜가 지정한 대로다 |

## 결과물 형식
- 인쇄용은 PDF. 워드에 붙일 그림은 A4 비율 이미지. 사용자가 나중에 직접 고칠 글자는 이미지에 박지 않는다.
- 한 개를 확정한 뒤 여러 학년·차시로 넓힐 때는 확정본의 스타일 값(글꼴, 크기, 간격)을 파일로 저장하고 그 값을 그대로 쓴다.

## 하지 않는 것
- 내용이 맞다는 이유로 레이아웃 확인을 건너뛰지 않는다.
- 보기 좋은 일부 예시로 전체를 대신하지 않는다.
