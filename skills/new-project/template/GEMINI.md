# {{PROJECT}}

전역 하네스 규칙(`~/.gemini/GEMINI.md`)을 따른다. 이 파일에는 이 프로젝트에만 해당하는 것을 적는다.

## 프로젝트
- 목적: (첫 작업을 받으면 사용자가 한 말 그대로 한두 줄)
- 결과물 종류: (미정)

## 먼저 볼 파일
1. `PROGRESS.md`: 지금 단계, 다음 할 일, 확정된 결정, 미확인
2. `docs/QUALITY_BAR.md`: 사용자 피드백에서 굳힌 품질 규칙. 결과물을 보내기 전에 항목별로 스스로 검사한다
3. `INDEX.md`: 폴더 지도

## 폴더 규칙 (하네스 표준)
| 폴더 | 용도 | 고쳐도 되나 |
|---|---|---|
| `input/` | 받은 원본 자료 | 안 됨(보호). `work/`로 복사해서 작업 |
| `work/` | 작업본, 중간 산출물, 실험 | 됨 |
| `output/` | 사용자에게 보낼 결과물 | 됨 |
| `output/확정/` | 사용자가 확정한 결과물 | 안 됨(보호). 바꿀 일이 있으면 새 버전을 `output/`에 |
| `handoff/` | 다른 AI·PC로 넘길 인계본 (`handoff-pack`) | `.zip`은 안 됨(보호). 새 버전으로 만든다 |
| `review/` | 검수 의견 (`review/gpt/`, `review/gemini/`). 읽기 전용 모드의 보고서 위치 | 됨 |
| `prompts/` | 다른 AI에게 줄 프롬프트 (`prompts/gpt/`) | 됨 |
| `docs/` | 품질 기준, 피드백 기록, 결정·보관 문서 | 됨 |

- 보호 목록은 `.gemini/protected.txt`. 하네스 훅이 이 목록의 파일 수정을 막는다.
- "분석만/검토만"이면 `.gemini/READONLY.example`을 복사해 `.gemini/READONLY`를 만든다(끝나면 지운다).
