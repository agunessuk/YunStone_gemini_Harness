# 환경 함정과 정리

FOD-skills `windows-env-pitfalls`, `macos-env-pitfalls`, `agent-resource-hygiene`, `safe-cleanup`에서 이 사용자에게 해당하는 부분만 합쳤다.

## Windows 함정
- 사용자 폴더 이름이 한글일 수 있다(예: `C:\Users\홍길동`). 경로는 항상 따옴표로 감싼다. 경로를 인자로 넘기는 스크립트는 UTF-8로 읽는다.
- Python은 `python`으로 실행하고 `PYTHONIOENCODING=utf-8`을 준다. 콘솔 출력이 cp949로 깨질 수 있으니 판단에 쓸 한글은 파일로 쓰고 읽는다.
- PowerShell 5.1: `&&` 없음. `Set-Content`·`Out-File`은 `-Encoding utf8`을 준다. 네이티브 명령에 `2>&1`을 붙이지 않는다.
- 기존 파일의 줄바꿈(CRLF·LF)을 확인하고 그대로 쓴다. Git Bash `sed -i`는 CRLF를 바꾼다. 업데이트 스크립트가 CRLF로 깨진 적이 있다.
- 백그라운드 서버가 exit code 4 같은 코드로 바로 죽으면: 포트 사용 중인지, 이전 서버 프로세스가 남았는지, 잠긴 파일(세션 lock)이 있는지 먼저 본다.

## Mac 함정
- `sed -i ''`, BSD 도구 옵션 차이. 디스크 용량은 `df`로 본다.
- Chrome·Acrobat 같은 앱 설정은 사용자가 직접 바꾼다. 방법을 단계별로 알려 준다.

## 서버·백그라운드 작업
- 띄울 때 PID, 포트, 로그 경로를 `PROGRESS.md`나 보고에 적는다.
- "서버 열어줘"면 접속 주소를 첫 줄에 쓴다.
- 작업을 끝낼 때 내가 띄운 서버·감시 프로세스·하위 에이전트를 끈다. 사용자가 테스트 중이면 끄기 전에 말한다.
- 내가 띄우지 않은 프로세스는 끄지 않는다.

## 정리와 삭제
| 등급 | 예 | 처리 |
|---|---|---|
| 내가 이번 작업에서 만든 임시 파일 | 압축 해제 테스트 폴더, 임시 스크립트 | 묻지 않고 정리 |
| 다시 만들 수 있는 것 | 빌드 산출물, 캐시 | 목록을 보여 주고 일괄 승인 |
| 이전 버전, 더미, 녹화, 원본 | 이전 인계본, 저품질 이펙트 | 항목별 승인. 안정화 전에는 백업 먼저 |
| 보호된 원본 | `.gemini/protected.txt` 목록 | 삭제 제안 안 함 |
- 삭제 전 전체 크기를 재고, 지운 뒤 줄어든 크기와 지운 목록(매니페스트)을 남긴다.
- 폴더째 지우는 명령은 하네스 훅이 사용자에게 확인을 받는다. 확인 창에서 무엇을 왜 지우는지 알 수 있게 명령 바로 앞에 한 줄 설명한다.
